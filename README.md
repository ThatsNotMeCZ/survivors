# survivors

Phaser 4 GPU smoke test and agent knowledge base for a VS × RoR2 hybrid.

```bash
bun install
bun run dev
```

Open `http://127.0.0.1:8080` — WASD, mouse aim, hold LMB, Shift dash. Smoke: `/?smoke=1`. Content: `src/data/*.json`.

Design and engineering notes: [`knowledge/README.md`](knowledge/README.md). Agent entry: [`AGENTS.md`](AGENTS.md).
