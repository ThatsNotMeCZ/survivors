# Hermetic Rifts — itch.io image set

Generated by `bun run capture:itch` (Playwright 1920×1080 + ffmpeg). Requires `ffmpeg` and `bunx playwright install chromium`.

Dev server on `:8080` is reused when already running.

## Upload map

| File | Size | itch.io field |
|---|---|---|
| `cover.gif` | 630×500, &lt; 3 MB | Edit game → **Cover image** |
| `cover.png` | 630×500 | static fallback if the GIF is rejected |
| `banner.png` | 960×240 | **Edit Theme → Banner** (replaces the page title) |
| `01-circle.png` | 1920×1080 | Screenshots |
| `02-boss.png` | 1920×1080 | Screenshots |
| `03-tablets.png` | 1920×1080 | Screenshots |
| `04-archives.png` | 1920×1080 | Screenshots |
| `gif-circle.gif` | 1280×720, &lt; 3 MB | Screenshots **or** inline in description HTML |
| `gif-boss.gif` | 1280×720, &lt; 3 MB | Screenshots **or** inline in description HTML |

Itch GIFs do not animate on mobile; keep the PNGs in the screenshot set.
